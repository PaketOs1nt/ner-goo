# ner-goo
A simple rhythm game built to learn and experiment with Godot.

![Godot](https://img.shields.io/badge/Godot-4.7-blue?logo=godot-engine)
![License](https://img.shields.io/badge/license-MIT-green)
[![Play on itch.io](https://img.shields.io/badge/itch.io-play%20now-FA5C5C?logo=itch.io&logoColor=white)](https://paketsoftware.itch.io/ner-goo)

## Features:
 - **Settings** - pick your FPS cap, toggle sound checks, turn V-Sync on/off, and save your preferences.
 - **Gameplay** - tap the squares in time with the beat. Each square lights up and changes color as it hits, so you always know when to press.
 - **Fun sync in menus** - menu colors and animations pulse and dance along with the music.
 - **Editor** - build your own beatmaps from scratch and play them right away.

### Hit notes with any of these inputs:
- `Z`
- `X`
- `Left Mouse Button`
- `Right Mouse Button`

Scroll mouse to change volume
